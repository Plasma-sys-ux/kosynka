# Косынка — неоновый пасьянс

Классическая «Косынка» (Klondike) в тёмном неоновом стиле. Работает прямо в браузере: без установки, без интернета и без регистрации.

- 3 уровня сложности, очки, время и счётчик ходов
- отмена хода, подсказка, автоматический добор в конце партии
- таблица 10 лучших результатов для каждого уровня
- 5 цветовых схем: «Киберпанк», «Матрица», «Закат», «Ультрафиолет», «Классика»
- карты можно перетаскивать мышью или пальцем, вёрстка подстраивается под телефон

---

## Как открыть игру у себя на компьютере

1. Откройте папку `public`.
2. Дважды щёлкните по файлу `index.html` — игра откроется в браузере.

Рекорды и выбранная тема запоминаются в самом браузере.
Важно: у игры, открытой с компьютера, и у игры на сайте — **разные** таблицы рекордов, это нормально.

## Что где лежит

```
kosynka/
├── public/            ← всё, что видит игрок (эту папку и выкладываем в интернет)
│   ├── index.html     — страница игры
│   ├── style.css      — оформление и цветовые схемы
│   ├── logic.js       — правила игры (ходы, очки, подсказка)
│   ├── game.js        — всё, что на экране: карты, кнопки, рекорды
│   ├── favicon.svg    — значок во вкладке браузера
│   ├── og-image.png   — картинка, которая видна, когда ссылкой делятся в мессенджере
│   └── _headers       — настройки безопасности и кеша для Cloudflare
├── wrangler.jsonc     — настройки для выкладки через командную строку
├── .gitignore         — список файлов, которые не нужно загружать в GitHub
└── README.md          — эта инструкция
```

Как добавить свою цветовую схему: в `style.css` скопируйте любой блок `[data-theme="…"]`, поменяйте цвета,
а в `game.js` добавьте строку в список `THEMES` (в самом начале файла).

## Как выложить игру в интернет на Cloudflare (бесплатно)

Понадобится бесплатный аккаунт Cloudflare: https://dash.cloudflare.com/sign-up

Ниже три способа. Выберите **один**. Способы 2 и 3 работают с одним и тем же проектом, способ 1 создаёт отдельный.

> Названия кнопок сверены с документацией Cloudflare (developers.cloudflare.com) в октябре 2026 года.
> Cloudflare иногда переименовывает кнопки — если что-то называется чуть иначе, ищите похожее по смыслу.

### Способ 1. Самый простой — перетащить папку мышкой (без командной строки)

1. Войдите в панель Cloudflare: https://dash.cloudflare.com
2. В меню слева откройте **Workers & Pages**.
3. Нажмите **Create application** (в старом интерфейсе — **Create**).
4. Найдите вариант **Drag and drop your files** («Перетащите файлы») и нажмите **Get started**.
   В старом интерфейсе этот путь выглядел так: вкладка **Pages** → **Upload assets**.
5. Введите имя проекта латиницей, например `kosynka`.
6. Перетащите в окно **папку `public`** целиком (не всю папку `kosynka`, а именно `public`).
   Можно перетащить и zip-архив этой папки.
7. Нажмите **Deploy site** («Опубликовать»).

Через минуту игра будет доступна по адресу вида `https://kosynka.pages.dev`
(если имя занято, Cloudflare добавит к нему несколько букв).

**Как обновить игру потом:** Workers & Pages → ваш проект → **Create a new deployment** («Новая публикация») →
выберите **Production** → снова перетащите папку `public` → **Save and Deploy**.

### Способ 2. Через командную строку

1. **Установите Node.js** — это программа, которая нужна для команды выкладки.
   Скачайте версию **LTS** с https://nodejs.org и установите, нажимая «Далее».
2. **Откройте командную строку в папке проекта.** В Windows: откройте папку `kosynka` в Проводнике,
   щёлкните по адресной строке сверху, напишите `cmd` и нажмите Enter.
3. **Войдите в свой аккаунт Cloudflare:**

   ```bash
   npx wrangler login
   ```

   Если спросит «Ok to proceed? (y)», нажмите `y` и Enter. Откроется браузер — нажмите **Allow** («Разрешить»).
   Пароль в командную строку вводить не нужно.
4. **Выложите игру:**

   ```bash
   npx wrangler deploy
   ```

   Команда сама прочитает `wrangler.jsonc` и загрузит папку `public`. В конце она напечатает адрес вида
   `https://kosynka.ваше-имя.workers.dev` — это и есть ваша игра.

**Как обновить игру потом:** измените файлы и снова выполните `npx wrangler deploy` из папки `kosynka`.

### Способ 3. Через GitHub — игра обновляется сама при каждом изменении

GitHub — это сайт для хранения файлов проекта. Если связать его с Cloudflare, то после каждой загрузки
изменений в GitHub сайт обновится сам.

1. Зарегистрируйтесь на https://github.com и создайте новый репозиторий (кнопка **New**), например `kosynka`.
2. Загрузите в него **всё содержимое папки `kosynka`**: папку `public`, файлы `wrangler.jsonc`, `.gitignore`, `README.md`.
   Проще всего — кнопкой **Add file → Upload files** на странице репозитория (или программой GitHub Desktop).
3. В панели Cloudflare откройте **Workers & Pages** → **Create application**.
4. Выберите **GitHub** (при первом подключении Cloudflare попросит разрешить доступ к GitHub — разрешите).
5. Выберите репозиторий `kosynka`.
6. В настройках оставьте всё как есть: поле **Build command** пустое, **Deploy command** — `npx wrangler deploy`.
   Нажмите **Save and Deploy**.

Готово: адрес будет вида `https://kosynka.ваше-имя.workers.dev`.

**Как обновить игру потом:** загрузите изменённые файлы в репозиторий на GitHub — через минуту-две
Cloudflare сам выложит новую версию. Ход выкладки виден в проекте: вкладка **Deployments** → **View build history**.

## Как привязать свой домен (например, `kosynka.ru`)

Сначала домен нужно купить у любого регистратора доменов. Дальше — в зависимости от выбранного способа.

**Если выкладывали способом 2 или 3 (адрес `…workers.dev`):**

1. Добавьте домен в Cloudflare: на главной странице панели нажмите **Add a domain** («Добавить домен»)
   и следуйте подсказкам. Cloudflare покажет два адреса **nameservers** — их нужно вписать в настройках домена
   у вашего регистратора (обычно раздел «DNS-серверы»). Переключение может занять до суток.
2. Откройте **Workers & Pages** → проект `kosynka` → **Settings** → **Domains & Routes** → **Add** → **Custom Domain**.
3. Введите домен (например, `kosynka.ru` или `play.kosynka.ru`) и нажмите **Add Custom Domain**.
   Cloudflare сам создаст нужные записи и бесплатный сертификат для https.

**Если выкладывали способом 1 (адрес `…pages.dev`):**

1. Откройте **Workers & Pages** → ваш проект → вкладка **Custom domains** → **Set up a domain**.
2. Введите домен и нажмите **Continue**, дальше следуйте подсказкам.
   - Для основного домена (`kosynka.ru`) его тоже нужно добавить в Cloudflare и сменить nameservers, как выше.
   - Для поддомена (`play.mysite.ru`) достаточно добавить у регистратора запись **CNAME**,
     которая указывает на `kosynka.pages.dev`.

**После того как домен заработает**, откройте `public/index.html` и в строке

```html
<meta property="og:image" content="og-image.png">
```

замените `og-image.png` на полный адрес, например `https://kosynka.ru/og-image.png`, и выложите игру ещё раз.
Так картинка-превью будет надёжно показываться в Telegram, WhatsApp и VK: многие мессенджеры понимают только полный адрес картинки.

## Если что-то пошло не так

- **На сайте старая версия.** Стили и скрипты кешируются на 5 минут. Подождите или обновите страницу
  с очисткой кеша: `Ctrl + F5` (на Mac — `Cmd + Shift + R`).
- **Открывается ошибка 404.** Проверьте, что выкладывали именно папку `public`, а не папку уровнем выше:
  файл `index.html` должен лежать сразу внутри выложенной папки.
- **Пишет, что `npx` не найден.** Node.js не установлен или командную строку открыли до установки — закройте её и откройте снова.
- **Рекорды пропали.** Они хранятся в браузере. Если очистить данные браузера или открыть игру в режиме
  «инкогнито», таблица будет пустой.

## Что можно улучшить дальше

- Сохранять незаконченную партию, чтобы после закрытия вкладки продолжить с того же места.
- Тихие звуки с кнопкой «выключить звук».
- Статистика: сколько партий сыграно и выиграно, лучшая серия побед.
- «Решаемые» раздачи: перед раздачей проверять, что пасьянс можно сложить.
- «Партия дня» — одна и та же раскладка для всех игроков.
- Установка на телефон как приложения (значок на рабочем столе).
- Общая онлайн-таблица рекордов — для неё уже понадобится сервер и база данных.
